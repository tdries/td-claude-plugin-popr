# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent. Assume good faith, critique the code rather than the person,
and accept that "no" is a complete answer to a feature request.

Report unacceptable behaviour to the maintainer through a
[private security advisory](https://github.com/tdries/td-claude-plugin-popr/security/advisories/new)
or by opening an issue if it is not sensitive. Reports are handled privately.
